# Third-Party Data Attributions

## NapierOne Dataset

The TESTS set includes a limited subset of files from the NapierOne Mixed File Dataset, maintained by Edinburgh Napier University.

**Dataset:** NapierOne Mixed File Dataset
**Authors / Maintainers:** Simon R. Davies, Richard Macfarlane, William J. Buchanan (Edinburgh Napier University)
**Source:** https://www.napierone.com/ and https://github.com/simonrdavies/NapierOne
**License:** Edinburgh Napier University License Agreement (found at https://registry.opendata.aws/napierone/)

**Usage in this repository:**
- Only a small number of **.RAR archive files** from the dataset are included (unaltered).
- These files are used for testing/demonstration purposes.
- This project is not affiliated with or endorsed by the original authors.
